# Trip Budget App

A trip budget management app for splitting expenses among group members.

## Features

- Add, edit, and delete expense items
- 13 group members with dropdown selector
- Per-person spending summary
- Settlement summary with average share calculation
- CSV export functionality
- Inline editing in the table
- Responsive design with Japanese font support
- Persistent storage with Supabase PostgreSQL

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Vercel Serverless Functions
- Database: Supabase PostgreSQL
- Deployment: Vercel

## Local Development

1. Clone the repository
2. Run `node server.js` to start local server
3. Open `http://localhost:3000`
